# PomodoroSwing

Java Swing alapú Pomodoro-időzítő MVC és Observer tervezési mintával.

## Funkciók
- 25 perces munka, 5 perces rövid és 15 perces hosszú szünet.
- Start, szüneteltetés és reset.
- Állapotfüggő színek.
- Konfigurálható időtartamok.

## Technológiák
Java 17, Swing, Maven, JUnit 5.

## Futtatás
Indítsd el a `pomodoro.Main` osztályt NetBeansből.

Tesztek futtatása:

    mvn test
